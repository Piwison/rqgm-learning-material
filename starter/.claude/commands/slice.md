---

把我們剛才談定的東西切成**可以一片一片做完並驗證**的工作。

## 唯一的切法：垂直，不要水平

**水平切（不要）：** 先做完所有 schema → 再做完所有 API → 再做完所有前端。
每一層都做完了，但在最後一刻串起來之前，**沒有任何一件事是可以驗證的**。

**垂直切（要）：** 每一片都從資料庫穿到畫面，做**一件很薄但完整的事**。

```
片 1：一個欄位，從 DB 存進去、API 讀得到、畫面顯示得出來
片 2：加上第二個欄位
片 3：加上錯誤狀態
```

每一片做完，都有一個**真的能操作的東西**。

> 這叫 tracer bullet（曳光彈）—— 出自《The Pragmatic Programmer》，
> Matt Pocock 的 AI coding 工作流沿用了這個詞。先打一發穿透全部圖層的子彈，
> 看它落在哪裡，再調整。

## 每一片必須符合

```
□ 有一個十秒內可確認的完成條件
□ 做完之後系統還是能跑的（不會留下半殘狀態）
□ 一次 session 做得完（做不完就再切一次）
□ 有標明它擋住誰 / 被誰擋住
```

## 輸出格式

```
### 片 1 · <名字>
動到：（檔案或模組）
完成條件：（二元、十秒內可確認）
擋住：片 3
風險：（沒有就寫「無」）
```

## 兩個規則

**切完先給我看，不要直接開始做。** 我要先確認順序。

**如果某一片你切不出「十秒內可確認的完成條件」，那一片就是還沒想清楚。**
不要硬切 —— 回報說這片需要再 grill 一次。
